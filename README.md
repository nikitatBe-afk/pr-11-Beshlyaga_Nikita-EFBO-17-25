# Практическая работа № 11 — вариант 4

Пакетный импорт клиентов из CSV на Java. Ошибка одной записи фиксируется с номером строки и не прерывает обработку остальных записей.

## Формат файла

```csv
inn;name;email;birthDate
1234567890;Иван Иванов;ivan@example.com;2000-01-01
```

`birthDate` — обязательная дата рождения в формате `ГГГГ-ММ-ДД`. Несуществующая и будущая даты отклоняются. Первая строка считается заголовком; пустые строки и строки с `#` в начале игнорируются. Повторный ИНН отклоняется как ошибка.

## Запуск

Требуется JDK с поддержкой `record` (Java 17 или новее).

```bash
bash run_selfcheck.sh
```

Скрипт компилирует исходники и запускает `SelfCheck`: 22 unit-проверки, 15 проверок по `data/sample.csv`, затем интерактивное меню. Для выхода из меню введите `0`.

Отдельные режимы после компиляции:

```bash
java -cp out ru.edu.pr08.SelfCheck unit
java -cp out ru.edu.pr08.SelfCheck data
java -cp out ru.edu.pr08.SelfCheck interactive
```

В Windows используйте `run_selfcheck.bat`. Файлы диаграмм редактируются в Graphviz DOT; чтобы обновить PNG, выполните `dot -Tpng diagrams/activity.dot -o diagrams/activity.png` и аналогично для `class.dot`.

## Возрастные категории

`ClientValidator.addAgeCategory(String birthDate)` возвращает `до 18`, `18–65` или `старше 65` на текущую дату. Возраст 18 и 65 лет входит в среднюю категорию.

Решения по варианту и контрольные вопросы находятся в [DECISIONS.md](DECISIONS.md). Отчёт — [REPORT11.docx](REPORT11.docx).

## Перед публикацией

Локальный Git `origin` указывает на репозиторий автора исходного проекта. Перед отправкой своего варианта задайте адрес собственного репозитория командой `git remote set-url origin <ваш-URL>` и внесите тот же адрес в `REPORT11.docx`.
